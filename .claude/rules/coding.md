# Coding Standards

- Полный рабочий код сразу, не фрагменты
- Никаких заглушек, TODO, pass без реализации
- Типизация Python: type hints обязательны в публичных функциях
- Pydantic для конфигурации (не os.getenv напрямую)
- Логирование через logging, не print
- Исключения: конкретные типы, не bare except
